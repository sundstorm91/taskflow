# TaskFlow — командная доска задач

TaskFlow — это fullstack-приложение для управления задачами с авторизацией, ролями (админ/пользователь), дедлайнами и фильтрацией.
Построено на **Next.js 15, Prisma, SQLite, Tailwind**.

---

## 🚀 Стэк технологий

- [Next.js 15](https://nextjs.org/) (App Router, Server Components, API Routes)
- [Prisma](https://www.prisma.io/) + SQLite (ORM и БД)
- [Tailwind CSS](https://tailwindcss.com/) (стилизация)
- [JWT](https://jwt.io/) (авторизация через httpOnly cookies)
- [TypeScript](https://www.typescriptlang.org/) (типизация)
